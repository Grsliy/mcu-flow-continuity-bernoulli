Fitur #1 — kontrol fisik

Isi-ulang ketinggian via PWM

User atur target ketinggian (potensio/tombol) → pompa mengisi Tangki Sumber dari Tangki Penampung → berhenti otomatis saat target tercapai (feedback dari Fitur #4).

Fitur #2 — kontrol fisik

Bukaan valve via servo

Servo memutar tuas valve di titik penyempitan → mengubah luas penampang efektif (A), independen dari ketinggian tangki sumber.

Fitur #4 — ukur fisika

Ketinggian → tekanan hidrostatis

Sensor ultrasonik ukur ketinggian air di Tangki Sumber → hitung P=ρgh real-time (ala Mulianti dkk.) → dibandingkan dengan ΔP dari Bernoulli.

Fitur #3 — presentasi

Sonifikasi & mode tantangan

Buzzer bernada mengikuti debit, LED status target, LCD kasih target debit untuk dicapai user — gamifikasi ringan, murni software.
